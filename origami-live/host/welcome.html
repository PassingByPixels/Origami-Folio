How to use it

  1. Open your deck in the Origami Studio (the browser extension).
  2. Click Go Live in the toolbar. Origami hands the deck to this helper.
  3. A localhost tab opens — your deck, playing like a web page. Edit and save; the live tab follows along.

Private by design

  • It serves to 127.0.0.1 (your machine only) by default — nothing is uploaded, no account, no cloud.
  • The server is read-only: it hands out the page and nothing else. There is no way for a viewer to change your files.
  • Sharing to the room is opt-in and key-gated — the link carries a one-time key, and viewers can only ever view, never edit. Windows asks once before it's reachable on your network.
  • It serves a temporary copy of the open deck — not your folders, not your other files.
  • It only runs while you're live. Close the tab or press Stop and the server is gone.

About the Windows warning

Origami Live is free, and we don't pay for a code-signing certificate yet — so Windows may show a blue "Windows protected your PC" screen the first time you run it. That's the unsigned-app warning, not a virus alert.

Click More info → Run anyway. If you'd rather check first, learn how it works at origamilabs.nl.
